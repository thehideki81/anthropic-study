# CCA Study Kit

Study tools for the Claude Certified Architect – Foundations exam. Skills live in `.claude/skills/`; the study docs they read are in `reference/study/` (paths in the skills are relative to this repo root).

- Practice only: never help with questions from the real, live certification exam.
- `reference/instructor.pdf` is the official exam guide. It is not in the repo (gitignored); each user installs or updates it with `/exam-guide-update`, never by hand. Never commit it. Never copy its sample questions or their answers into the study docs or a mock exam.
- When refreshing `reference/study/`, add a dated `CHANGES-<date>.md` and keep every key fact cited to a primary Anthropic source.
